# Areth Design 住宅営業用 3D太陽軌道シミュレーター
**3D Solar Path Simulator for Housing Sales & Training**

日本国内の任意地点・任意日付について、日の出から日の入りまでの太陽の動きを3D空間で直感的に可視化し、住宅営業・研修でのPC画面共有に最適化したWebアプリケーションです。

中央に**2階建て参考住宅モデル（南面大開口・軒・バルコニー）**を配置し、**太陽の動きに連動したリアルタイムの日影シミュレーション**に対応しています。

## 1. アプリ概要

住宅商談において、お客様へ次のポイントを1分以内に直感的に説明できることを主目的としています。
- **夏は太陽が高い軌道を通る**（軒・庇によって南面窓が日影に入り、日射を遮蔽）
- **冬は太陽が低い軌道を通る**（軒の下をくぐって室内の奥深くまで暖かい陽が差し込む）
- **日影の1日の動き**（朝は西側へ長く、正午は足元へ短く、夕方は東側へ長く伸びる）
- **季節による南中高度の違い**（夏至・春分/秋分・冬至の比較）
- **季節による日の出・日の入りの方位の違い**（春分・秋分は概ね真東〜真西、夏至は北寄り、冬至は南寄り）
- **時刻ごとの太陽高度と方位角の変化**（リアルタイム数値と3D連動）

## 3. 対応ブラウザ・動作環境

- **推奨ブラウザ**: Google Chrome 最新版、Microsoft Edge 最新版、Safari 最新版、Firefox 最新版
- **必須確認環境**: Windows 11 (Google Chrome / Microsoft Edge)
- **WebGL**: WebGL 2.0 推奨（ソフトシャドウマップ対応、非対応時は日本語案内表示）
- **画面解像度**:
  - PC画面共有推奨: 1440×900 / 1920×1080（スクロール不要で主要操作可能）
  - タブレット（768px〜1023px）: 縦スクロール型で快適にプレゼン利用可能
  - スマートフォン（〜767px）: 3Dビュー上部、操作系下部の最適化配置

## 5. 太陽位置計算 & シャドウ仕様

- **採用アルゴリズム**: 天文計算ライブラリ `SunCalc`（v1.9）をコアとし、日本国内向けに真北0°時計回りの厳密座標変換ラッパー（`src/astronomy/solarPosition.ts`）を構築。
- **南中計算**: 単純な12:00固定ではなく、太陽高度が極大となる時刻・高度を探索アルゴリズムで1分以内で特定。
- **リアルタイム日影**: Three.jsのソフトシャドウマップ（`PCFSoftShadowMap`）と太陽位置同期のDirectionalLightを使用。太陽が地平線下にある夜間は自動的に影が消去されます。
- **2階建て住宅モデル**:
  - 間口8m × 奥行6m × 高さ6m（1階3m、2階3m）
  - 南面（-Z方向）にリビング掃き出し窓、バルコニー、出幅約0.9mの軒（庇）を配置。
  - 操作パネルの「参考住宅モデル（2階建て & 日影）」チェックボックスで表示/非表示を自由に切り替え可能。
